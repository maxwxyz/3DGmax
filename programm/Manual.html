3DGmax – Manual

3DGmax shows 3D models with their PMI (dimensions, geometric tolerances, datums, notes). The PMI are read semantically – as values that can be evaluated, not only as pictures. This lets you show tolerance zones, measure, compare two states in geometry and PMI, and document reviews. Deutsch: Anleitung.

Shortcuts: Ctrl means ⌘ on the Mac. Single keys such as F or G work when the 3D view has the focus (click into it once).

Quick start

  1. Open: drag a STEP file into the window or use File › Open (Ctrl+O).
  2. Navigate: drag with the middle button to pan, middle + left button to rotate, the wheel zooms (CATIA style, can be changed). F fits all, 1–7 are the standard views.
  3. Look at PMI: click a PMI in the list on the right – its faces and datum system light up in the model. Clicking a face shows its PMI.
  4. Compare: File › Compare, choose the old and the new state. Yellow = changed, green = new, red = removed; the Changes list leads through all differences.
  5. Try it: File › Examples opens ready-made demonstrations with free test data: PMI and views, check PMI, tolerance zones, section view, comparisons, scan against tolerances, tolerance stack-up.
  6. Find a command: Ctrl/⌘+K searches all commands by name (also in German), with menu path and shortcut; Enter runs it, commands not available right now are grey.
  7. Help: F1 opens this manual, Help › Introduction the short introduction.

Opening models, formats

  • File › New window (Ctrl/⌘+N) and Open in new window … show several models side by side; Window › Couple the cameras of the windows rotates and zooms all of them the same way.
  • File › Open, drag and drop, or double-click an associated file (on macOS, Finder offers 3DGmax under “Open With” for all readable formats). Loading runs in the background, Cancel in the status bar discards it.
  • With PMI: STEP AP242 (also AP214/AP203 without PMI), STEPZ (zipped), QIF 3.0, 3D PDF/PRC (graphical PMI).
  • Geometry only: IGES; meshes STL, OBJ, glTF/GLB, 3MF, PLY (e.g. scans) – view, measure, analyse and compare against CAD. JT 8 and 9 as mesh with structure, names and colours in the program variant with the JT reader TKJT; TKJT cannot read JT 10 (the message says so – export as JT 9 or STEP).
  • If a file holds only the graphics of a PMI (no semantics), 3DGmax derives kind and values from the text or the markup type; such entries are marked ≈ (“derived from the graphics – please check”).

The window

  • Structure: assembly and parts; check boxes show and hide, right-click: isolate, show all, transparent.
  • Saved views: views from the file with thumbnails; ＋ Remember stores your own.
  • PMI: all characteristics with kind, characteristic, name, value, datums, faces and views; columns can be moved and shown/hidden (right-click the header).
  • Quick measure (right of the status bar): length, ⌀/R, area, distance, angle of the selection; right-click chooses the values.
  • All panels can be shown and hidden under Window and arranged freely; the layout is remembered. Stacked panels appear as tabs: the ✕ on a tab closes a panel, a right-click on the tabs shows other panels (they join this tab group).

PMI

  • Clicking a PMI highlights faces and annotation and shows the datum system; clicking a face selects all PMI of that face; clicking an annotation selects its PMI.
  • Search (Ctrl+F): free text or bezug:A, wert:0.5, typ:position, art:toleranz, ansicht:MBD_A, ballon:3.
  • Right-click in the list: zoom, align, select datums, tolerances using this datum, show tolerance zone, show in view, edit, copy.
  • Show graphical PMI (G) shows and hides the annotations, Shift+G shows only the selected ones. If a file has semantics only, 3DGmax generates a display (violet, switch: View › Show generated PMI display).
  • Balloon numbers (B) number the characteristics as in the bill of characteristics (export PDF/CSV). Tools › Read measurement results (QIF) assigns the actual values of a QIF results file to the characteristics (designator = balloon number, otherwise name), assesses them against the limits and enters them in the list.
  • Standard (Model › Standard): ASME Y14.5 or ISO GPS, detected automatically; it sets terms and checks. Model › Check PMI finds e.g. missing datums, PMI without faces, or orientation tolerances without a datum, and checks the specification for plausibility: contradictions (form tolerance not smaller than orientation/location, two dimensions with different values), incomplete specifications (untoleranced faces), datum system, implausible values, nominals that do not match the model, basic dimensions with a tolerance, location toleranced twice (toleranced location dimension and position/profile to the same datum), pattern dimensions on features of different size and too few datum targets (plane as primary 3, secondary 2, tertiary 1) and gear data in notes (z, m, αn, β, x) against the recognised gear. Double-click selects the PMI or the faces.
  • File › Save STEP with edited PMI writes edited nominal sizes, deviations and tolerance values into a copy of the STEP file – only the affected numbers change, everything else stays byte-identical. Fit class and Ⓜ/Ⓛ are changed too. The report lists what could not be written and PMI whose graphics still show the old values. Own PMI (datums, geometric tolerances, size and distance dimensions) are appended as semantic AP242 PMI – also in assemblies (per part; a PMI across several parts is reported).
  • Basic dimensions are shown in square brackets [75], reference dimensions in round ones (75).

Saved views

◀ ▶ or PgUp/PgDown browse the views, “(No view – all PMI)” removes the filter. ＋ Remember stores the current camera with the PMI and measurements shown as an own view (in the project and the PDF). Right-click in the list: thumbnails small (default), large or off. Section views from the file (STEP AP242 with clipping planes) cut the model open when the view is chosen; Section › No section or another view removes the cut again.

Structure and display

  • Display: Shaded with edges (E), Shaded (S), Wireframe (W; clicks also pick hidden edges).
  • Highlight selection (Shift+T, also in the context menu): everything except the selected faces, PMI and parts (selection in the structure) becomes translucent.
  • Parts: H hide selection, I isolate, T transparent, Shift+H show all.
  • Explode (X) pulls assemblies apart level by level (slider in the toolbar, next to it the direction: radial or only along X, Y or Z); Model › Parts list groups equal parts with quantity, volume and mass.
  • Model properties (Ctrl+I): volume, mass (density adjustable), centre of gravity, size, file header.
  • Show auxiliary geometry: points and lines without faces, e.g. construction geometry.

Section

  • View › Section: plane normal to X, Y, Z, at the selected face or edge, from the view direction, or a section box around the selection.
  • Keep section plane collects up to three planes; normally everything behind any plane is cut away, with Cut away common region only only the region behind all of them (e.g. a quarter section).
  • Export section contour: the section lines of all planes as SVG, DXF or PDF.

Measuring

  • Distance (two elements, with dX/dY/dZ), Angle (planes, axes, lines), Radius/⌀, Wall thickness (normal into the material), Coordinates.
  • Snapping to end points, edge midpoints and circle centres; navigation keeps working, Esc ends measuring.
  • Copy, Save CSV and File › Export › Measurement report (PDF).

Tolerance zones

View › Show tolerance zone (or right-click a PMI or the model) shows where faces and axes may lie within the tolerance – for the selected PMI or, without a PMI selection, for the PMI on the selected faces. Show all tolerance zones shows all at once. Narrow zones are exaggerated (factor in the status bar).

View › General tolerances … adds ISO 2768-1/-2 or ISO 22081 for faces without their own specification (violet); if a note in the file states them, they are suggested. Zones are shown at the nominal location. Orientation and form zones may float within the higher-level zone – the turquoise envelope shows it.

Analysis, tolerance stack-up, creating PMI

  • Model › Analysis: draft angle, curvature radius or wall thickness as a colour map; a click shows the value.
  • Model › Tolerance stack-up: add selected dimensions with + or −, or select faces in the model in chain order (Ctrl/⌘) and use ＋ From 3D selection: each two consecutive faces form a link, the direction comes from the first planar face, the sign from the position. Values come from the matching PMI dimension (also for patterns), otherwise from the general tolerance ISO 2768 (chosen or stated as a note in the file), otherwise “no tolerance” (red). Distribution per link by production type – normal (series, with Cp), triangular (small batch), trapezoidal (flat part a), uniform (one-off), folded normal (form, runout) and Rayleigh (position) – skewed from the lower limit – or from measured values (button in the column Cp / Form: paste values or load a CSV; the sample mean and σ give offset and Cpk); the Share column shows as a bar how much each link contributes to the spread. Double-click the direction to reverse a link. The closing dimension is shown in a table: arithmetic (worst case) always, plus statistical (±3σ) and Monte Carlo. Bold with ✓ is the applicable method: statistical only from four effective contributors (one dominating link counts as one), otherwise arithmetic – the reason is given below, the histogram shows the Monte Carlo distribution with worst case and requirement. Selecting a row highlights its faces in the model. What-if … makes the table editable by double-click (nominal, limits, tolerance, distribution, Cp, offset, direction) without touching the chain: changed values are bold, the result is shown as actual | what-if | Δ; Apply makes the what-if the chain, Discard restores the actual one. Save … keeps the what-if as a named scenario (the list loads it again, Compare … shows the actual chain and all scenarios side by side; they are stored in the chain file). With Location tolerances, position, symmetry, coaxiality and profile with datum of the first and last face are added as links of their own (the location of intermediate faces cancels out). With Ⓜ/Ⓛ the location link grows by the full bonus in the worst case (size tolerance of the feature), a datum with Ⓜ/Ⓛ adds a link of its own ("datum shift"). Straight and circular edges may be chain ends too. Offset per link (process mean offset) lowers the Cpk; with Requirement on the closing dimension the window shows Cp, Cpk and the share outside (normal distribution and Monte Carlo). PDF report with picture, result table (also what-if against actual), reason, histogram and link table; the chain is stored in the project. Thermal expansion at two limit temperatures computes ΔL = α · L · (T − 20 °C) per link with the material of its part (from the STEP file, otherwise from the library; Materials … changes α and sets an own temperature per part if needed). ＋ Length range … adds springs, shims or adjusting screws between smallest and largest length; right-click makes a link the adjusting member, the window then states the range it must cover for the requirement. Directions from closing dimension: select the two faces of the closing dimension (the planar one first), the program finds the path through the links and sets order and signs; ▶ Walk chain shows the links one after another in the model, each as a line between its faces (+ green, − red, with value). Save chain … writes a .3dgkette file that Open chain … or File › Open loads later together with its model. Example: File › Examples › Stack-up gearbox shaft. Next to Process capability Cp you choose the statistical method: RSS, RSS × Bender factor (margin, default 1.5) or mean shift (per link the mean shifts by the share m of the half tolerance, added arithmetically, the rest varies statistically). The Factor column is a link's sensitivity (e.g. 2 for a 2:1 lever). In the what-if, Allocate tolerances … sets the tolerances that are not fixed to a target range of the closing dimension – equal variance per link (equalise) or proportional; links marked Fixed when allocating (right-click) stay. Correlation … (right-click) groups links that vary together (e.g. dimensions of one part from one set-up) – with ρ between 0 (independent) and 1; statistics and Monte Carlo then use covariances.
  • Model › Create PMI: select faces, check, adjust and accept the suggestions of the tolerancing advisor (own PMI, stored in the project). Existing PMI can be edited; the original values stay visible.

Comments

K on selected faces or PMI creates a comment, question or change request with a marker in the model. The Comments panel shows open/done; export as CSV or PDF, stored in the project.

Comparing two states

  • File › Compare (Ctrl+Shift+V): choose the old and new state, tolerance (up to this a face counts as equal) and search distance (up to this changed, beyond new/removed).
  • Shifted states are aligned automatically (best fit); File › Manual alignment uses point pairs.
  • Detected: changed, new, removed, moved, rotated and mirrored elements; in assemblies changed, new, removed, moved and renamed parts, parts used several times per instance (the change list names the affected instance; selecting zooms to it and marks it in the tree).
  • PMI are matched by kind, type, common faces, value, datums and name and compared field by field (value, deviations, zone, datums …); “geometry under PMI changed” reports equal PMI on changed geometry.
  • Deviation colour map shows the deviation per point (scale, tolerance limit, value on click); Material + / − shows added and removed volume like CATIA.
  • Compare folders: all models of two folders in pairs with an overview.

Comparison modes

While comparing, the View bar above the 3D view (shortcuts Alt+1 … 6) offers Comparison (new state coloured by status, removed faces red), Old and New (one state only), Overlay (old state transparent blue over the new one), Side by side (old left, new right, cameras coupled: rotating, zooming and standard views act in both) and Blink (switches at the chosen speed, ⏸/▶ pauses, Space switches by hand; in Old/New Space switches too). Highlight changes colours changed faces and PMI in Old, New, Side by side and Blink. In Old mode the structure tree shows the old state, in Side by side both trees are shown one below the other (the old one below; its check boxes act on the left view); a selected change is highlighted in both states. The tree shows the status of every part: ● new, ● changed, ● removed (in Old mode); assemblies with changes below carry a •.

Reviewing changes

  • The table shows per change the characteristic, old, new and Δ (for PMI the changed field, for geometry the largest deviation or displacement, for assemblies the volume) and the tendency: tolerance tighter (red) or looser (green). Right-click the column headers to hide or show columns.
  • Start review leads step by step through the changes; Checked / Rejected with a comment.
  • Finish review: reviewer, result, remark → report with checksum (SHA-256), stored in the project.
  • Reports: File › Export › Comparison report (PDF), PMI changes (PDF), Changes (CSV).

Assembly and degrees of freedom

Tools › Assembly and degrees of freedom: select a face on the part that is to move, then with Ctrl/⌘ the mating face on another part and Connect. Two planes are placed against each other (at a distance with Offset), two cylindrical or conical faces are aligned coaxially. Cylinder and plane give a pin in a slot (axis parallel to the flank at the distance of the radius, line contact), sphere and plane a point contact, two spheres a ball joint. The part jumps to its new position. Part instances are moved one by one. With a part selected in the list, a 3D handle shows only the arrows and rings of its open degrees of freedom – dragging moves the part while the connections stay satisfied. 3-2-1 locates a part in one step: pick six planes in pairs (part, counterpart) – primary (3 points), secondary (2), tertiary (1); three plane-on-plane connections are created.

  • The connections table shows whether each connection is still satisfied in the current position (a later connection may move an earlier one). Reverse turns the moved part of the selected connection by 180° (cylinder end for end, on a plane half a turn), Swap parts lets the other part move.
  • The parts table lists the open degrees of freedom of each moved part (translation along, rotation about); parts that are only mating parts count as fixed. A screw with head contact and coaxial shank has one left: the rotation about its axis.
  • Move part: for the selected part there is one field per open degree of freedom (mm or degrees); the part moves only as its connections allow, Back to the starting position restores it.
  • Wiggle moves the selected part back and forth in each open degree of freedom in turn (travel in mm, angle in degrees) – this shows whether all intended connections are set.
  • Clearance per connection: planar ± along the normal (half the sum of the location and profile tolerances of both faces, plus tilt from all face tolerances), coaxial the radial clearance from the diameters (geometry, size tolerances or general tolerance) plus position tolerances, checked at the ends of the common length. Double-click changes the value. From this follows the position scatter of each part: how far its corners can move in X, Y and Z in the worst case (linear model, all connections at once; free degrees of freedom do not count).
  • Wiggle within the tolerances moves to the limits of the clearance one after another, 1:1 or exaggerated.
  • The clash check uses the parts in their assembled position; connections, positions and measures are stored in the project.

Measures (second tab): select two parallel planes on different parts – first the measured one, then with Ctrl/⌘ the reference face – and Measure from selection. Facing faces give a gap, faces pointing the same way a flush (distance of the face centroid to the reference plane); a cylinder and a parallel plane give axis to plane, two parallel cylinders the axis distance. All connections vary at once within their clearances:

  • Worst case: smallest and largest value over all connections (linear program).
  • Monte Carlo: clearances normally distributed (clearance = 3σ), 99.73 % range, mean and σ; when a part is over-constrained, the tighter connection decides its position.
  • Requirement by double-click (e.g. 3.8 … 4.2, ≥ 1): share outside and Cpk.
  • Contributors of the selected measure: worst-case range when only this connection varies, and its share of the variance – this shows which tolerance to change.
  • If the measure depends on open degrees of freedom, a note says so: connect the parts completely first. As PDF … saves connections, results and contributors. Example: File › Examples › Assembly variation.

Clashes and distances

Tools › Clashes and distances checks the parts of an assembly in pairs: all against each other, only the parts selected in the structure against each other, or the selected parts against the rest (part instances count separately). Mesh parts (STL, OBJ, glTF, PRC meshes …) are checked via their triangles; distance, volume and depth are then approximations to about the mesh size and marked “≈”.

  • Clash: the parts intersect, with the intersection volume.
  • Contact: touching up to the contact tolerance (default 0.01 mm), can be switched off.
  • too close: distance below the minimum distance (clearance); too far: distance above the maximum distance – only with “against the rest”, otherwise every distant pair would be a finding.
  • Select a finding: the two parts stay opaque, the rest becomes translucent, the intersection appears in red, the minimum distance as a line with its value. Per finding a status (open, accepted, ignored) and a comment (double-click); Save CSV to pass it on, PDF report with an overview picture and the findings table.
  • For clashes the volume and depth of the penetration are given (smallest edge of its oriented bounding box); the intersection curves of the surfaces are shown with the penetration.
  • Also at the tolerance limit positions: each connected part of the assembly is also checked at the limits of its clearance; reported is what only collides or comes too close there (column Kind: “limit position”). Directly connected parts are left out – the connection defines their relative position.
  • Range of motion of open DOF (± mm, ± degrees): each part with open degrees of freedom is moved along each degree of freedom up to the first collision. Above the table is the free range per degree of freedom; the collision at the limit is listed in the table (“at …”). Collisions that already exist in the start position do not count.
  • Settings, statuses and comments are stored in the project; when opening, 3DGmax checks again and matches them to the part pairs.

The computation runs in the background (progress bar with Cancel at the bottom). Tapped holes with screws at nominal size appear as clashes if the model does not cut out the thread – mark such findings as “accepted”.

Recognise gears

Tools › Recognise gears reads the gear data of the selected parts (without selection: all visible ones) from the geometry – cylindrical gears external and internal, spur and helical, also from meshes (STL …), and involute spline shafts and hubs (30°, ISO 4156 / DIN 5480). Measured are the number of teeth, tip and root diameters, face width, helix angle with hand and the base circle (involute fit of the flanks in a transverse section); derived per ISO 21771 are the normal module and pressure angle (the pair with the nearest standard module per ISO 54; ambiguities are reported), the reference diameter, the profile shift (from the tooth thickness at the reference circle) and the span measurement Wk. The table states the origin of each value; CSV and JSON export the values for gear and system design tools. Meshing gear pairs (parallel axes, also a pinion in a ring gear) are listed in a second table: measured and backlash-free centre distance, working pressure angle, transverse and overlap contact ratio and the normal backlash from the centre distance. Parts without involute flanks (hexagons, knurls) are not reported.

Meshes and scans

Meshes (STL, OBJ, PLY, glTF, 3MF) can be viewed and measured like CAD models and compared against a CAD model: alignment is automatic (best fit) or manual with point pairs, the colour map shows the deviation of the scan per point.

Tools › Check scan against tolerances (with a CAD model with PMI open): choose the scan – it is aligned automatically and fitted finely onto the exact faces. The colour map lies over the translucent CAD model, the Scan check panel evaluates every PMI: OK, not OK, at the limit (within the measurement uncertainty), – not evaluable. Form tolerances are evaluated as range, profile and location within the zone, axes and diameters via a best-fit cylinder (with bonus for Ⓜ/Ⓛ), roundness and circular runout per cross-section (the worst section counts). Clicking a row selects the PMI – with “Show tolerance zone” you see where the scan leaves the zone. Result as CSV.

  • Point clouds without triangles are checked the same way: XYZ, ASC, TXT, CSV, PTS (x y z per line, comma, semicolon or space, also decimal comma) PLY with points only and E57 (all scans with their pose); the colour map appears as coloured points.
  • Alignment in the panel: best fit over all points or datum system A|B|C (3-2-1) – the primary datum is fitted, the secondary only in the remaining degrees of freedom, then the tertiary (least squares per datum; with Contact (ISO 5459) each datum touches the highest points outside the material, the largest distance is minimal – sensitive to outliers). Evaluate again uses the chosen alignment. By hand … sets the start position from point pairs between scan (blue, transparent) and model – with little overlap or symmetric parts –, followed by fine alignment and, if chosen, the datum reference frame.
  • Linear and angular dimensions are evaluated too: distance of the best-fit planes (or axes) of both sides and angle between the best-fit planes.
  • Inspection report (PDF): header with model, scan and alignment, overview picture, table of all PMI and one page with a picture for each PMI outside or at the limit.
The evaluation is an approximation for visual inspection, not a standard-conforming evaluation by measuring strategy.

Export and drawings

  • File › Export: views as PDF (picture and PMI per view), bill of characteristics (PDF/CSV), measurement report, comments, comparison report, PMI changes, PMI as CSV.
  • Drawing: standard views, current view, saved views or section views (per section plane the rest behind the plane, cut face hatched per ISO 128, section A–A …) as PDF, SVG or DXF; Sheet format places them on a standard sheet A4–A0 with frame, title block and the largest fitting standard scale; PMI in drawings adds the annotations.
  • Save image or Copy image (Ctrl+Shift+C) for the 3D view.

Project

File › Save project (Ctrl+S) stores the model or comparison with review state, comments, measurements, own PMI and views in one .3dgmax file – to pass on. Open it with File › Open.

Settings

  • File › Settings: mouse navigation (CATIA/Classic), background, PMI colour (readable default or colours from the file) and more.
  • View › Color scheme: light, dark or like the system; View › Language: German/English (at the next start); View › Size of the interface: 90 to 150 % (at the next start).

Questions

Why don't I see any PMI? The file has none (e.g. STEP AP214) or the selected saved view shows only some – choose “(No view – all PMI)”.

What does ≈ in front of a PMI mean? The file holds only graphics for it; kind and values were derived from them and should be checked.

Why is a tolerance zone so thick? Narrow zones are exaggerated for display; the factor is in the status bar.

A part looks translucent. Tolerance zones or “Highlight selection” are switched on (View menu).
