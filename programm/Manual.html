3DGmax – Manual

3DGmax displays 3D models with PMI (dimensions, tolerances, datums) from STEP files (AP242). PMI is read semantically, i.e. as evaluable values – not just as a picture. Two revisions can be compared and reviewed in geometry and PMI.

Open a model

  • File › Open (Ctrl+O) or drag a file into the window. Supported: STEP AP242, AP214, AP203 (.stp, .step).
  • File › Recent files and the start page list the last files.
  • Loading runs in the background; Cancel in the status bar discards the result.

PMI

  • The PMI list (right) shows all dimensions, geometric tolerances and datums with value, tolerance, datum reference frame (e.g. ⌖ | ⌀0.75 | A | B | C) and the number of associated faces. Filter by type and search (Ctrl+F) narrow the list.
  • Click a PMI to highlight its faces and its annotation in the model in orange.
  • Click a face to select all PMI of that face in the list; clicking an annotation selects its PMI.
  • Basic dimensions are shown in square brackets [75], reference dimensions in parentheses (75).
  • Show graphical PMI (G) toggles the annotations in the model. If the file has no ready-made graphics, 3DGmax writes the text from the semantics.

Saved views

The list at the bottom left shows the views stored in the model. A view sets the camera and shows only the PMI of that view (also in the list). “(No view – all PMI)” removes the filter.

Structure, display, section

  • Check boxes in the structure show and hide parts; right-click: Isolate, Show all, Transparent.
  • Display: Shaded with edges (E), Shaded (S), Wireframe (W).
  • Section: plane normal to X, Y or Z; the slider moves it, the cut face is filled in orange.
  • Show auxiliary geometry: points and lines without faces (e.g. construction geometry) are hidden otherwise.
  • PMI color: By default annotations are shown in a well readable color for the light or dark scheme. Can be switched off under File › Settings – then the file colors apply (CATIA e.g. white).
  • View › Color scheme: light, dark or like the system. View › Language: German/English (on next start).

Measure

  • Tools › Measure (M) opens the “Measure” panel. Choose a measurement, then click in the model; navigation keeps working. Esc ends measuring.
  • Distance: two elements (point, edge, face) – shortest distance with dX/dY/dZ.
  • Angle: two planes, axes (cylinder, cone, circle) or lines; the supplement to 180° is shown too.
  • Radius / Ø: circle, arc, cylinder, sphere, cone (reference radius), torus (minor radius).
  • Wall thickness: a spot on a face; measured perpendicular into the material up to the opposite face.
  • Coordinates: X, Y, Z of a point.
  • Snap (check box): close to end points, edge midpoints and circle centres the point snaps there.
  • Results appear in the list and in the model; Delete, Delete all, Copy and Save CSV (semicolon, decimal comma).

Compare two revisions

  • File › Compare … (Ctrl+Shift+V): choose old and new revision, tolerance (up to here a face counts as equal) and search distance (up to here as changed, beyond as new/removed). Offset revisions are aligned automatically by best fit.
  • The new revision is colored: grey equal, yellow changed, green new; removed faces of the old revision red.
  • The Changes panel lists PMI and geometry changes numbered (old → new). A click jumps to the location.
  • Start review steps through; Checked (G) / Rejected (A) jump to the next open change, plus a comment.
  • Finish review: reviewer, result, remark → report (JSON and text) with SHA-256 checksum – not a qualified electronic signature.
  • Compare folders: all models of two folders pairwise (pairing by file name, revision suffix ignored), overview equal/changed/only old/only new; double-click opens the comparison.

Check and export

  • Model › Check PMI: unused or missing datums, PMI without face or view, duplicates, orientation tolerance without datum and more; double-click selects the PMI.
  • File › Export: views as PDF (one page per saved view with image and PMI), comparison report (PDF, image per change), PMI changes (PDF) for suppliers, PMI and changes as CSV. Exports follow the selected language.
  • File › Save project (Ctrl+S): model or comparison with review status, comments and measurements as one .3dgmax file (to send); open via File › Open.

Images

File › Save image saves the 3D view as PNG, Copy image (Ctrl+Shift+C) copies it.

Limits of this version

  • STEP only. JT, 3D PDF, QIF and other formats will follow. Deviation color map and graphical PMI comparison will follow.
  • For parts used several times in an assembly, a PMI is highlighted on all occurrences.
